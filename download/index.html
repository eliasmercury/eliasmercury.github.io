Это тот же файл, что ставит приложение?

Да. Ссылка ведёт на GitHub Releases living-motion-releases. SHA-256 на этой странице совпадает с файлом. Preview-сборку так обновить нельзя.

Как потом обновлять?

Внутри приложения, без магазина. Нужна production-сборка com.livingmotion.coach. Телефон сам скачает новый APK, когда выйдет версия.

Xiaomi не ставит?

HyperOS часто спрашивает установку дважды. Разреши источник, открой файл из загрузок ещё раз. Если на телефоне Living Motion Preview — это другой пакет, его эта страница не обновляет.

Есть iPhone?
